# Architecture Decision Records (ADR)

Registro corto de las decisiones de arquitectura importantes: qué se decidió, cuándo, y por qué.

**Para qué sirve**: evitar que dentro de seis meses alguien (incluido tú) rediscuta desde cero una
decisión ya tomada, sin conocer el contexto que la motivó. También sirve para saber cuándo una
decisión merece reconsiderarse — cada ADR incluye qué tendría que cambiar para invalidarla.

**Cómo escribir uno**: copia `0000-plantilla.md`, numéralo consecutivo, y manténlo corto (una
página). No documentes cada decisión — solo las que fueron difíciles, costosas de revertir, o que
alguien va a cuestionar después.

**Regla**: un ADR no se edita una vez aceptado. Si la decisión cambia, se escribe uno nuevo que
lo reemplace y se marca el viejo como "Reemplazado por ADR-XXXX".
